# AI Investment Agent Frontend

React + Vite + Tailwind CSS v4 + Recharts dashboard for the **AI Investment Agent**.

For full architecture diagrams, setup instructions, API reference, and workflows, see the [root README](../README.md).

## Commands

```bash
npm install
npm run dev      # Start Vite dev server (http://localhost:5173)
npm run lint     # Run ESLint
npm run build    # Build production bundle into dist/
```
